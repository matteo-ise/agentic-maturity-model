> This repository is part of a conceptual infrastructure for Agentic Commerce. It serves as a **Proof of Concept (PoC)** and framework blueprint.

A maturity model for agentic enterprise transformation — 6 stages from Chaos (0) to M2M-Autonomy (5). 

## Stages
- **Level 0 (Chaos):** Manual processes, no AI tools.
- **Level 1 (Knowledge Indexed):** Internal knowledge base indexed.
- **Level 2 (Internal Agents):** Siloed agents automating internal tasks.
- **Level 3 (Internal MCP):** Unified tool access via internal MCP.
- **Level 4 (Public MCP):** Public-facing `/.well-known/mcp.json` endpoints.
- **Level 5 (M2M Autonomy):** Fully autonomous agent-to-agent negotiations.
